调用 read_quota 展示面板，或直接点击侧栏“额度时间环”，无需提问。真实额度来自本机官方 Codex App Server，只代表返回额度桶，不代表所有 ChatGPT 模型限额。自然周期及实际重置以服务返回为准。

read_reset_signal 匿名只读查询获授权的 GitHub 公开监测项目，不传额度或账号数据。它独立提供网友额外重置估计，必须保留来源、时区假设、区间与更新时间。推断不等于官方排期或确定兑现；过期不能自动顺延，不能声称额度已恢复。

只在用户明确要求演示时调用 demo_quota。真实读取失败保留并标记旧值，不拿模拟数值冒充真实数据。插件不修改 ChatGPT 左下角内置图标，不要求修改认证、安全或权限。安装入口与最终图标效果需在目标 App 确认。
